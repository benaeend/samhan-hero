# 삼한 용사 키우기

고구려 건국 신화와 우리 옛이야기 속 세상을 지키는 방치형 RPG입니다. 비스듬히 내려다보는 쿼터뷰 화면에 2~3등신 캐릭터가 나와요. 👉 **https://benaeend.github.io/samhan-hero/**

📖 플레이 매뉴얼(PDF): [docs/manual.pdf](docs/manual.pdf) · 📝 업데이트 노트: [UPDATE_NOTES.md](UPDATE_NOTES.md)

휴대폰 홈 화면에 앱으로 설치할 수 있어요(설치하면 주소창 없이 열리고, 인터넷 없이도 돌아가요).

- 아이디·비밀번호로 계정을 만들고, 한 계정에 캐릭터 4명까지(옷 색·머리색·피부·머리 장식 꾸미기).
- 네 직업(무사·자객·술사·도인). 직업마다 기술 6개와 초각성기 하나.
- 1분 프롤로그와 이야기 80장: 해모수와 유화, 알에서 태어난 주몽, 엄리대수, 졸본 → 환생 → 저승의 열 대왕 → 사신의 귀환. 퀘스트를 깰 때마다 짧은 연출.
- 용사는 알아서 사냥해요. 몬스터 10마리 → 보스, 각 지역 9번째 단계는 수문장. 초반은 빠르게, 중반부터는 한 단계에 몇 시간씩 방치.
- 장비 소환·합성(등급에 따라 모습이 바뀜), 재련 +25(실패할수록 확률이 오르고 담금질 기운이 차면 확정 성공), 신화 보물, 장신구(반지·귀걸이·팔찌), 사신 변신
- 공격·방어·지원 펫 15종 소환·강화
- 레이드(이승 레벨 10마다, 저승은 시왕 레이드), 나 + 같은 기기의 다른 캐릭터 + NPC 동료로 3~10인 자동 전투
- 3시간마다 나타나는 타임 보스(2명 이상, 노말·지옥)
- 환생: 이승 Lv.100·무기 +25·다섯 시련 → 윤회 구슬로 영원한 능력 → 저승(Lv.200까지)
- 상점, 채팅, 국악풍 배경음악·효과음
- 계정과 기록은 온라인 서버(Supabase)에 저장돼서 다른 기기에서도 같은 아이디로 이어서 해요. 인터넷이 끊기면 기기에 저장했다가 다시 올려요. 창을 닫아도 최대 12시간까지 오프라인 보상이 쌓여요.

## 개발

- 원본: `src/game.html` → `python3 tools/build.py` 로 `index.html` 생성
- 확인: `python3 tools/test_game.py` (밸런스는 `--long 100`), 매뉴얼: `python3 tools/make_manual.py`
