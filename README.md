# 삼한 용사 키우기

옛 한국풍 도트 그래픽의 방치형 RPG입니다. 👉 **https://benaeend.github.io/samhan-hero/**

- 아이디·비밀번호로 계정을 만들고, 한 계정에 캐릭터 4명까지 만들어요(옷 색·머리색·피부·머리 장식 꾸미기).
- 네 직업(무사·자객·술사·도인) 중 하나를 골라 시작해요. 직업은 언제든 바꿀 수 있어요.
- 길잡이 까치가 튜토리얼로 안내하고, 이야기 퀘스트와 오늘의 할 일로 보석을 받아요.
- 용사는 알아서 사냥해요. 몬스터 10마리를 잡으면 보스가 나타나요. 잡몹도 가끔 보석을 떨궈요.
- 장비 소환·합성, 재련(+20까지, 실패할수록 확률이 오르는 방식), 공격·방어·지원 펫 소환·강화
- 레벨 10마다 레이드가 열려요. 나 + 같은 기기의 다른 캐릭터 + NPC 동료로 3~10인 자동 전투(토벌패 3개, 15분마다 1개 충전)
- 상점(자동 탕약·부적·숫돌·토벌패·오늘의 선물), 퀘스트 보상 때 가끔 기술 초기화·신화 보물, 주민들과 채팅
- 지역: 마을 어귀, 대나무 숲, 바위 고개, 안개 늪, 도깨비 굴, 백두 설원
- 진행 상황은 브라우저에 자동 저장돼요(계정도 그 브라우저 안에 있어요). 창을 닫아도 최대 12시간까지 오프라인 보상이 쌓여요.

## 개발

- 원본: `src/game.html` → `python3 tools/build.py` 로 `index.html` 생성
- 확인: `python3 tools/test_game.py` (밸런스는 `--sim`)
