# 시험용 캐릭터 (베타 테스트 빌드 전용)

`python3 tools/build.py --beta`가 이 폴더의 `*.json`을 파일 이름 순서로 모아 `beta/index.html`의 「시험용 캐릭터로 시작」 목록에 넣는다. 본 게임(`index.html`)에는 들어가지 않는다.

파일 하나 = 캐릭터 하나:

```json
{"name": "시험무사", "label": "3부 끝 무사", "desc": "곤륜 Lv.500 · 이야기 182", "save": { …게임 저장(S) 그대로… }}
```

- `name`은 한글·영문·숫자 2~8자(겹치면 뒤에 숫자가 붙는다).
- `save`는 진행 시뮬(`tools/test_game.py`의 SIM)이 남긴 저장을 쓰되, 날짜·시각이 들어간 칸(오늘의 할 일·상점·레이드 횟수·부적 등)은 비워서 넣는다(`mergeState`가 기본값으로 채운다).
