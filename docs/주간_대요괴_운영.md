# 주간 대요괴 운영 안내

## 처음 한 번 해야 할 일
1. Supabase 사이트 → SQL Editor를 연다.
2. `supabase/setup.sql` 내용을 통째로 붙여 넣고 Run을 한 번 누른다. 여러 번 실행해도 기존 기록은 그대로다.
3. 그 전에는 대요괴가 서버 없이 「내 계정 대요괴」(같은 계정의 캐릭터끼리만 합침)로 돌아간다. 함수가 만들어지면 다음에 열 때 저절로 서버 전체 모드가 된다.

## 규칙 요약
- 한 주 = 한국 시간 월요일 0시 ~ 일요일 밤. 보스는 주마다 4마리가 돌아가며 나온다.
- 목표 = 1,000 × max(3, 지난주 참가한 캐릭터 수). 막대 25·50·75·100%마다 보상(캐릭터마다 한 번).
- 캐릭터 하루 3번, 계정 하루 6번(서버의 한국 날짜 기준).
- 지난주 점수 1~3등은 이번 주 한 주 동안 겉모습 별호를 단다.

## 이상한 기록 SQL로 지우기
점수가 이상한 캐릭터를 찾아(예: `select * from samhan_wb order by score desc limit 20;` 와 `samhan_wb_log`) 지울 때, SQL Editor에서 아래 한 줄을 쓴다(이름 `수상한용사` 부분만 바꾼다).

```sql
delete from samhan_wb where name = '수상한용사' and wk = to_char(date_trunc('week', now() at time zone 'Asia/Seoul')::date, 'YYYY-MM-DD');
```

기록 표(`samhan_wb_log`)에도 같은 캐릭터의 판별 기록이 남아 있으니, 하루 횟수까지 되돌리려면 `delete from samhan_wb_log where acc = '계정아이디';`를 더한다.

## 주의
- 표 두 개는 게임에서 직접 읽거나 쓸 수 없게 잠겨 있다(함수만 열림). SQL Editor에서만 만진다.
- 실제 키(`secret`·`service_role`)는 어디에도 적지 않는다.
