# 진행 시뮬 저장 (물의 신화 작업용)

`python3 tools/sim_full.py <직업>`이 남긴 저장이다(2026-11-11, 1단계 밸런스 패치 뒤 코드로 네 직업을 처음부터 3부 끝까지).

| 파일 | 때 |
|---|---|
| `save_<직업>_q113.json` | 1부 이야기 113개를 마치고 부상에 막 건넌 때(Lv.240, 2차 전직) |
| `save_<직업>_q145.json` | 2부를 마치고 곤륜에 막 들어선 때(Lv.400, 3차 전직) |
| `save_<직업>_end.json` | 3부 끝(Lv.500, 4차 전직, 이야기 182) — **4부 시뮬·밸런스의 출발점** |

쓰는 곳: 4부·5부 진행 시뮬의 출발점(`opts.load`), 추천 조합 재기(`tools/sim_skpre.py`), 베타 시험용 캐릭터(`tools/beta_save.py` → `tools/beta_saves/`).
밸런스를 크게 바꾸면 다시 만든다. 게임(`index.html`)에는 들어가지 않는다.
