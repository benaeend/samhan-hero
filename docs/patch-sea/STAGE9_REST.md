## 나눠 맡길 때의 공통 규칙 (지시서 맨 앞에 붙인다)

1. 문서·코드가 매우 길다: `CLAUDE.md`(20만 자)·`src/game.html`(1만 9천 줄, 한 줄이 수백 자)·`PROGRESS.md`(13만 자)는 **통째로 읽지 말고** `grep -n '이름' 파일 | cut -c1-200`으로 자리를 찾아 `sed -n 'a,bp' … | cut -c1-600`으로 필요한 줄만. 본보기가 되는 4부 기능을 먼저 읽고 같은 틀로 만든다.
2. 고친 뒤 `python3 tools/build.py` → `python3 tools/test_part.py '<시작 머리>' '<끝 머리>'`(한 대목 1~2분) → 끝에 `python3 tools/test_game.py`(전체 6분, 결과는 끝날 때 한꺼번에). 코어가 둘이라 무거운 명령을 동시에 돌리지 않는다(여럿을 함께 돌릴 땐 `flock <잠금 파일> <명령>`). 「수군 야행: 밀물이 두 번…」 한 줄은 운에 따라 드물게 실패한다(이 세션에서는 일곱 번에 한 번 — 용사가 잠긴 쪽에 8초 넘게 머문 판).
3. **여러 일감을 동시에(작업 폴더를 나눠) 돌릴 때 부딪히지 않게** — 갈래마다 글자(A~H) 하나를 주고:
   - 시험 훅은 `window.__game`의 긴 목록 줄을 고치지 말고 `// @@HOOK-<글자>` 바로 아래에 `Object.assign(window.__game, {…});`
   - 새 저장 칸의 기본값은 `mergeState`의 `// @@MERGE-<글자>` 바로 아래에(`SAVE_BUILD`는 그대로 2)
   - 자동 점검 대목은 `tools/test_game.py`의 `# @@TEST-<글자>` 바로 아래에(따로 돌리기: `test_part.py '# 9-22)' '# @@END-<글자>'`)
   - 목록·표(`PETS`·`MOUNTS`·`AVATARS`·`TITLES`·`SOULS`·`SK_LIST`·`MYTHS`·`SETS`·`CRAFT_T`…)의 **맨 끝에 붙이지 말고 관련된 4부 항목 바로 뒤에** 끼운다
   - `UPDATE_NOTES.md`·`CLAUDE.md`·`docs/**`·`NOTES`/`NOTE_VER`·`tools/make_manual.py`는 한 갈래만(또는 메인이) 고친다. 다른 갈래는 넣을 글을 보고에 적는다. `index.html`은 커밋에 넣지 않고 메인이 합친 뒤 빌드해 넣는다.
4. 5부 것은 세계 8 이상에 들어서야 열리게(3부·4부 용사에게 안 보이는지 점검에 넣는다), 예전 저장이 깨지지 않게, 이야기·전직 조건을 운에 걸지 않게.
5. 인도 옛이야기에서 지금도 섬기는 분(라마·시타·하누만·제석천·야마·연꽃 위의 여신 등)은 적·펫·탈것·넋 구슬로 쓰지 않는다. 싸우는 상대는 락샤사·아수라·라후·브리트라·마라. 다른 게임·영화·애니메이션의 그림·이름·대사를 가져오지 않는다(그림은 게임이 직접).
6. 5부의 그림 열쇠·지역/레이드 표·퀘스트 번호는 `CLAUDE.md`의 「5부 천축」 줄들에 있다. 이야기 연출을 고치면 `__game.cutCheck(68)`(없는 배경·인물·말한 사람을 찾아 줌)부터.
